# Tycoon RNG: Refinery Build Optimizer
High performance, web based build optimizer

## How to use
1. Go to the URL: https://staticstate.github.io/trr-build-optimizer/
2. Select an item, select its modifiers and the quantity and click "Add", repeat for every item in the inventory
3. Click "Start" on the "Optimization" section

You can Import/Export your inventory in this format: <br>
Item1|Modifier1|Modifier2|Modifier3|Quantity <br>
Item2|Modifier1|Modifier2|Modifier3|Quantity <br>
Ore Lifetime|x% <br>
Income|x% <br>
(The Ore Lifetime sections should have your respective Ore Lifetime and Income from the <ins>Skill Tree</ins>)

Example:
Energy Compressor|OP|H|10
Sandy Valley|1
Ancient Gate|OP|N|H|16
Hands of Ancient|N|1
Steampunk Orb|3
Ore Lifetime|65%
Income|150%

Pressing "Export" will download a text file with this formatting, pressing "Import" after pasting your inventory with this formatting will automatically set the inventory up
